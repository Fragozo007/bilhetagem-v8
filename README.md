# bilhetagem-v8

App PWA de controle de bilhetagem, viagens e fechamento de turno.

## Uso local

Abra `bilhetagem-v8.html` no navegador ou sirva a pasta com um servidor estático.

## Arquivos principais

- `bilhetagem-v8.html` — interface
- `bilhetagem-v8.js` — lógica
- `bilhetagem-v8.css` — estilos
